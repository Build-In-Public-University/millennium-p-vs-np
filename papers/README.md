# Paper generators

A paper generator is a pre-paper. It earns a paper only by surviving contact with evidence, proof, computation, experiment, or close reading.

Template:

```markdown
# Paper generator: <working title>

- Status: seed / testing / draft / submitted / retired
- Authors:
- Target venue or audience:

## One-sentence claim

## Why this matters

## Contribution type

- theorem / counterexample / dataset / method / experiment / synthesis / creative work

## Minimum result required

## Method

## Prior work and novelty boundary

## Falsifier

## Reproducibility or provenance plan

## Next action
```
