# Connection ledger

A connection is not a metaphor. It is a proposed transfer of structure, method, object, data, or proof technique.

Template:

```markdown
# Connection: <A> ↔ <B>

- Status: proposed / partially supported / tested / rejected
- Author(s):
- Date: YYYY-MM-DD

## Shared structure

## What transfers

## What does not transfer

## Testable prediction or usable construction

## Evidence

## Failure mode
```
